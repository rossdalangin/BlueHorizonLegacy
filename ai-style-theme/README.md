# AI Style Theme

A high-end, professional WordPress landing page design for an elite AI intelligence platform. The aesthetic is "Flat" and minimalist—strictly avoiding 3D effects, heavy shadows, or embossed elements.

## Key Features

- **Aesthetic:** Minimalist, flat design with a high-authority corporate feel.
- **Color Palette:**
  - **Primary:** Deep Navy Blue and Charcoal (#001f3f, #121212).
  - **Accent:** Teal (#00b4b4) and Gold (#c5a028) for CTAs and highlights.
- **Typography:**
  - **Headings:** Montserrat (Bold, clean sans-serif).
  - **Body:** Inter (Light-weight, crisp sans-serif with generous line height).
- **Layout Templates:**
  - **Front Page:** High-end hero section with systematic dashboard-like grids.
  - **Wide:** Full-width page template without sidebar.
  - **Sidebar:** Standard template with a registered widget area.
  - **No Header/Footer:** Minimalist template for focused landing pages or standalone tools.
- **Design Elements:** Ultra-clean flat vector icons (SVG) and sharp geometric borders.

## Installation

1. Download the `ai-style-theme` folder.
2. Upload the folder to your WordPress installation's `/wp-content/themes/` directory.
3. Log in to your WordPress dashboard.
4. Navigate to **Appearance > Themes**.
5. Locate **AI Style Theme** and click **Activate**.

## Theme Customization

- **Menus:** Go to **Appearance > Menus** to set up your primary navigation.
- **Widgets:** Use **Appearance > Widgets** to add content to the sidebar.
- **Front Page:** To use the custom landing page, go to **Settings > Reading** and set "Your homepage displays" to "A static page", then select your desired page as the Homepage.

## Development
