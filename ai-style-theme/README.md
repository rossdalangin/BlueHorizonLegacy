# AI Style Theme

A high-end, professional WordPress landing page design for an elite AI intelligence platform. The aesthetic is "Flat" and minimalist—strictly avoiding 3D effects, heavy shadows, or embossed elements.

## Key Features

- **Aesthetic:** Minimalist, flat design with a high-authority corporate feel.
- **Dynamic Content:** All homepage sections, modal contents, and lead-gen forms are 100% manageable via the **WordPress Customizer**.
- **Responsive Navigation:** Sophisticated mobile menu with overlay navigation and hamburger toggle.
- **Color Palette:** Deep Navy, Charcoal, Teal, and Gold "Blue Chip" corporate palette.
- **Typography:** Montserrat for Headings, Inter for Body (Manageable via Customizer).
- **Layout Templates:**
  - **Front Page:** High-end modular landing page.
  - **Wide:** Full-width page template.
  - **Sidebar:** Standard template with registered widget area.
  - **No Header/Footer:** Minimalist template for focused tools.
- **Dual-Mode Modal:** Supports both Iframe-based and Contact Form 7-based lead generation.

## Installation

1. Upload the `ai-style-theme` folder to `/wp-content/themes/`.
2. Activate the theme via **Appearance > Themes**.
3. **Critical Step:** Navigate to **Settings > Reading** and set "Your homepage displays" to "A static page", then select your desired page as the Homepage to enable the modular `front-page.php`.

## Customization

Go to **Appearance > Customize** to manage:
- Global colors and fonts.
- Hero, Marquee, and Service sections.
- Partner programs and Industry lists.
- Modal FAQs, benefits, and comparison tables.
- Footer logos and copyright info.
